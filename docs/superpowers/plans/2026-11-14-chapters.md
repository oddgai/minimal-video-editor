# Chapter Editing Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. The user authorized these changes and delegated detailed design.

**Goal:** Replace in/out cutting with split/select/delete chapters and the requested shortcuts.
**Architecture:** Source-time chapters remain FFmpeg export ranges; the pure Editor derives compact timeline positions, selection, and history. UI maps seeks and skips deleted ranges with the existing player.
**Tech Stack:** TypeScript, pnpm, Tauri 2, Rust, FFmpeg, Playwright.
**Spec:** `docs/superpowers/specs/2026-11-14-chapters-design.md`

## Global Constraints
- Keep lossless export, pnpm, and lightweight native playback.
- Deleted chapters disappear and close gaps; preserve source coordinates for export.
- Command/Ctrl+S export; arrows keyframes; S split; Command/Ctrl+arrows chapters; D delete.

## Review Focus
- Source ends, existing boundaries, non-keyframes, and deleted gaps cannot create empty chapters.
- Deleting first/middle/last/all chapters preserves selection and undo/redo.
- Compact splice seeks resolve to the following source range.
- Keyframe navigation and playback cannot enter deleted ranges.
- Input editing, focused buttons, and export locking remain usable.

## Follow-up: navigation during playback

The user requested that navigation continue playback. Removed explicit pauses from keyframe, chapter-selection, scrubber, and time-jump navigation. Paused navigation stays paused; seeking to the edited end explicitly stops. Split/delete/history/export retain their existing pause behavior.

A real-media regression test first reproduced ArrowRight pausing playback, then verified keyboard/button navigation, scrubbing, sidebar/timeline chapter selection, command-arrow selection, time jumps, paused navigation, and end stopping. `pnpm test` passes 17 tests, `pnpm test:ui` passes 7, and TypeScript checks pass.

## Follow-up: repeated backward navigation

After making navigation continuous, playback advanced slightly beyond each requested keyframe. The next backward request therefore selected the same GOP start again. A real-media regression reproduced the failure after moving forward to 8 seconds, then pressing Left while playback continued.

Track the last requested keyframe as the navigation origin until normal playback crosses the following retained keyframe. Other seeks, pauses and source changes clear the target; paused navigation keeps using the exact playhead. Clamp terminal navigation without repeatedly rewinding at the first/last keyframe.

The new test verifies backward progression 8→6→4→2→0 while playing, keyboard/button parity, returning to the live playback position once it advances, and paused navigation. All 17 model tests and 8 browser/real-media tests pass, as does TypeScript checking.

The full run also exposed a pre-existing preview boundary timing issue: a decoder delivered the excluded 4.000-second frame when currentTime was still 3.979 seconds. Boundary scheduling now accounts for one source-frame duration plus scheduling margin (bounded by half the retained span). The decoded-frame exclusion test remains strict and passes.
