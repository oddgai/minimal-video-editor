# ADR 0006: LGPL構成のFFmpegをアプリに同梱する

## 背景

現在のアプリは `ffmpeg` と `ffprobe` を別途インストールしておく必要がある。利用開始の手間を減らすため、macOSとWindows向けのアプリ配布物にこれらを同梱する。FFmpegのビルドに含める機能や外部ライブラリによってライセンス条件が変わるため、HomebrewのFFmpegをそのまま再配布する方法は採用しない。

## 決定

配布用バイナリは対象OS・CPUごとに用意し、GPLおよびnonfree機能を含めないFFmpegビルドを使う。ビルド元、設定、バージョン、チェックサム、適用されるライセンスと対応ソースコードの入手方法を記録し、アプリ配布物とともに必要な通知を提供する。

開発時には `MVE_FFMPEG` と `MVE_FFPROBE` による明示指定、およびシステムにインストールされた実行ファイルの利用を引き続き可能にする。同梱版を利用する場合は、アプリ内リソースからOS・CPUに合う実行ファイルを解決する。

## 影響

- 初回起動時のFFmpeg手動インストールを不要にできる。
- アプリの配布サイズが増え、macOSとWindowsの各対象向けにバイナリの作成・更新が必要になる。
- 配布前に、採用するビルドと全ての依存ライブラリのライセンス、通知、ソース提供要件を確認する必要がある。
- 本ADRの採用だけではバイナリは同梱されない。配布用バイナリの調達または再現可能なビルドと、パッケージへの追加が完了するまで、現行アプリにはFFmpegの別途インストールが必要である。

## 検討した代替案

- **利用者にFFmpegを別途インストールしてもらう:** 配布サイズとバイナリの保守負荷は抑えられるが、初回設定の手間が残るため採用しない。
- **Homebrewなどの既成バイナリをそのまま再配布する:** 入手しやすいが、ビルド設定や依存ライブラリのライセンスをアプリ側で管理できないため採用しない。
